## 原问题

For any $t\in (0,1)$ let $t=\sum_{k=1}^\infty \epsilon_k(t)2^{-k}$ (where $\epsilon_k(t)\in \{0,1\}$). What is the correct order of magnitude (for almost all $t\in(0,1)$) for\[M_n(t)=\max_{x\in [-1,1]}\left\lvert \sum_{k\leq n}(-1)^{\epsilon_k(t)}x^k\right\rvert?\]

### 主要障碍

- “正确量级”本身需要精确定义：是通常大小、所有充分大 n 的上下界、limsup/liminf，还是下类函数；这些版本难度和答案可能不同。
- 已知结果显示 M_n(t) 可能在不同 n 上有显著波动，单一 Θ 量级未必能简单描述，需要处理几乎处处序列级波动。
- 端点随机游走、靠近端点的指数加权和、以及内点区域的有界方差过程高度相关，不能用独立网格的粗糙并联合界直接得到 sharp 结论。
- 关键下界很可能涉及小偏差概率、Chung 型 LIL 或 Banach 空间下类理论；这是模型容易产生看似合理但缺少严密概率估计的区域。
- 若要证明最优对数因子，必须控制所有大 n，而不是只证明无穷多个 n 或概率趋近 1；Borel-Cantelli 依赖性和尺度嵌套会成为主要技术障碍。

- 首先明确待验证命题的形式，例如 M_n = n^{1/2+o(1)}、M_n = O(√(n log log n))、liminf 阶为 √(n/log log n)，或其他更精细版本。

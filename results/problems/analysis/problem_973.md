## 原问题

### 支持理由

- 问题形式非常清楚：变量是 n 个复数，约束为 z_1=1 与 |z_i|>=1，目标是前 n 个非平凡幂和的最大模；这适合数值优化、符号实验和候选结构搜索。
- 目标只要求存在某个 C>1，而不是要求最优常数；这降低了构造端的门槛，AI 可以通过实验寻找一个可证明的指数衰减族。
- 备注中已有相邻情形：|z_i|<=1 时存在指数小构造，max |z_j|=1 的极值也有精细指数估计；这些说明问题处在可量化的指数渐近框架内。
- 已有下界 (2e)^(-(1+o(1))n) 与所问存在性并不矛盾，因为它本身仍是指数小；因此工具辅助模型可以尝试在下界指数尺度附近寻找上界构造。
- 形式化验证有用：一旦找到显式构造族，幂和估计可能被拆成有限恒等式、尾项界、最大模界等可机械检查的子引理。

### 主要障碍

- 核心困难是量词为“对每个 n”，有限 n 的数值可行性不能直接证明统一指数构造。
- 约束 |z_i|>=1 与已知 |z_i|<=1 构造方向相反；简单取倒数、共轭或缩放通常不会保持幂和小和 z_1=1 这两个性质。
- 目标涉及 k=2 到 n+1 的一整段幂和同时很小，局部优化容易产生不可推广的偶然解。
- 若最优点允许部分 |z_i|>1，幂和对大 k 极其敏感，稳定性和误差控制会比单位圆问题更困难。
- 备注给出的精细常数来自经典分析，不太可能仅靠自动搜索直接补齐证明，需要提炼出新的结构性解释。

### 需要的验证

- 对 n 的较大范围进行高精度多启动优化，并记录最优值的指数率是否稳定低于某个 C^{-n}。
- 检查数值最优解的模长分布：是否全部接近 1，是否出现成对/共轭/根分布结构，是否能导出显式族。
- 对候选构造建立严格误差界，最好能覆盖所有 n 而不是只覆盖子序列。
- 若走反例方向，需要证明对任意 C>1 都存在 n 使目标不可能小于 C^{-n}；这需要强于当前备注中下界方向的非指数小结论。
- 需要核对 Ha74、Tu84b、Er92f 中相关定理的精确定义与约束，避免把 max |z_j|=1、|z_i|<=1、|z_i|>=1 三个问题混同。

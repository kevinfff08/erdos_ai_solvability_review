## 原问题

Let $C>0$. There exists $\epsilon>0$ such that if $n$ is sufficiently large the following holds.

For any $x_1,\ldots,x_n\in [-1,1]$ there exist $y_1,\ldots,y_n\in [-1,1]$ such that, if $P$ is a polynomial of degree $m<(1+\epsilon)n$ with $P(x_i)=y_i$ for at least $(1-\epsilon)n$ many $1\leq i\leq n$, then\[\max_{x\in [-1,1]}\lvert P(x)\rvert >C.\]

### 支持理由

- 命题有明确的有限 n 形式：给定点集后寻找标签 y_i，并排除一族度数约 n、区间上一致有界的多项式。这适合转化为有限维线性代数、凸几何或覆盖数问题。
- 模型可用计算搜索处理小 n 和特殊点集，例如等距点、Chebyshev 点、聚集点、重复点，从而检验 ε 与 C 的可能依赖关系，并发现潜在反例结构。
- 问题的工具链相对清晰：Remez 不等式、Chebyshev 多项式、插值基函数增长、Littlewood/符号选择思想、离散到连续范数控制，都能被模型系统性组合和验证。
- 命题不要求显式最优常数，只需存在 ε>0；这降低了目标强度，使概率方法或粗覆盖论证存在推进空间。

### 主要障碍

- 最困难点是“任意 x_1,...,x_n”，包括高度聚集或重复的点集；常规随机符号或等距网格论证未必能统一处理这些退化配置。
- 允许多项式次数 m<(1+ε)n，但只要求命中至少 (1-ε)n 个点；这种接近插值阈值的多数匹配条件非常紧，简单维数计数不够。
- P 的约束是连续区间上的 sup norm，而命中条件只在离散点上，必须把离散组合结构与连续多项式极值精确连接。
- 若 y_i 允许实数而非仅 ±1，构造空间更大但证明排除所有 P 也更复杂；需要控制无限多候选多项式，而不是有限标签类。
- Erdős 备注显示相关反向陈述在 m=n 情形已很难，说明直接套用经典插值估计可能不足。

### 需要的验证

- 对特殊点集进行数值实验：等距点、Chebyshev 点、指数聚集点、重复点块，测试是否存在 sup norm ≤ C 且命中多数标签的低度多项式。
- 建立并验证一个有限覆盖/净化引理：区间上 ||P||∞≤C、deg<(1+ε)n 的多项式在任意 n 点上的可能取值集合可被足够小的网覆盖。
- 检查随机 ±1 标签是否已足够；若不足，确定需要实值 y_i 的哪种构造。
- 证明退化点集的处理方式，例如重复点可否通过分块、多数投票或压缩到不同点后保留命题。
- 把候选证明中的连续不等式部分形式化或至少用 Lean/Isabelle 验证关键有限维引理，避免隐藏的常数依赖错误。

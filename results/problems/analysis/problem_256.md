## 原问题

Let $n\geq 1$ and $f(n)$ be maximal such that for any integers $1\leq a_1\leq \cdots \leq a_n$ we have\[\max_{\lvert z\rvert=1}\left\lvert \prod_{i}(1-z^{a_i})\right\rvert\geq f(n).\]Estimate $f(n)$ - in particular, is it true that there exists some constant $c>0$ such that\[\log f(n) \gg n^c?\]

### 支持理由

- 问题有明确的解析表达式，计算工具可以对给定 a_i 序列做高精度单位圆最大值搜索，并可用于发现极端构造模式。
- 备注给出较完整的已知进展路线，尤其明确指出 Belov-Konyagin 已证明 log f(n) << (log n)^4，这使模型可较可靠地完成特定子问题的验证性工作。
- 问题与三角多项式、乘积多项式、概率构造、Chowla cosine problem 等已有理论相连，适合用文献检索和证明分解工具建立可审计的路线图。
- 重复允许的 a_i 使 f(n) 与 f*(n) 区分明确，模型可以围绕重数结构搜索可能接近最坏情形的构造。

### 主要障碍

- 完整估计 f(n) 不是单纯计算问题；它需要全体整数多重集上的一致下界或极端构造，理论难度高。
- 已知下界 f(n)>sqrt(2n) 与 polylog 指数上界 log f(n) << (log n)^4 之间仍存在结构性鸿沟，模型很难凭局部实验闭合。
- Belov-Konyagin 型上界可能依赖精细概率或调和分析构造，重建细节和检查常数、量词、重复元素条件都需要严谨文献验证。
- 单位圆最大模问题数值上可能有尖峰和高频振荡，计算搜索容易给出误导性的候选极值或漏掉全局最大值。

### 需要的验证

- 核对 Belov-Konyagin 结果是否正是针对本题允许重复的 f(n)，而非只针对严格递增版本 f*(n)。
- 确认 polylog 上界 log f(n) << (log n)^4 的量词足以推出不存在 c>0 使 log f(n) >> n^c。
- 对任何模型提出的新上下界，必须给出全量词证明：对任意 a_i 的下界，或构造一族 a_i 的上界。
- 数值实验需使用区间证明、高精度采样加导数/根隔离等方式验证单位圆最大值，而不能只依赖离散网格。
- 若形式化，需先形式化 f(n) 的定义、单位圆参数化、乘积多项式连续性和最大值存在性，再逐步形式化引用引理。

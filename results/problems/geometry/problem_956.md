## 原问题

If $C,D\subseteq \mathbb{R}^2$ then the distance between $C$ and $D$ is defined by\[\delta(C,D)=\inf_{\substack{c\in C\\ d\in D}}\| c-d\|.\]Let $h(n)$ be the maximal number of unit distances between disjoint convex translates. That is, the maximal $m$ such that there is a compact convex set $C\subset \mathbb{R}^2$ and a set $X$ of size $n$ such that all $(C+x)_{x\in X}$ are disjoint and there are $m$ pairs $x_1,x_2\in X$ such that\[\delta(C+x_1,C+x_2)=1.\]Determine $h(n)$ - in particular, prove that there exists a constant $c>0$ such that $h(n)>n^{1+c}$ for all large $n$.

### 支持理由

- 题目允许自由选择一个紧凸集 C，这给 AI 搜索构造留下较大空间；不必解决一般单位距离问题即可可能改进下界。
- 距离条件可通过差体和凸体外平行体表达，适合符号化、线性/二次不等式验证和形式化证明。
- 目标下界只要求存在某个固定 c>0 的超线性构造，弱于精确确定 h(n)，也弱于逼近已知上界 n^{4/3}。
- 多边形凸体的情况可离散化为有限多个边、顶点和圆弧条件，计算机搜索与证明助手都有可用切入点。
- 备注中已有上界和与点集单位距离的平凡下界，说明主要突破点集中在新构造，而非需要立即推翻强上界。

### 主要障碍

- 核心难点不是验证单个配置，而是构造适用于所有大 n 的无穷族并证明边数达到 n^{1+c}。
- 凸平移必须两两不相交，这会排除许多看似高密度的差向量图构造。
- 若候选 C 依赖 n，仍需严格控制所有非边对不会相交、边对距离恰为 1，参数空间容易出现隐藏退化。
- 从小规模计算搜索提炼出可证明的渐近族可能很难，尤其需要避免只得到线性或近线性边数。
- 完整确定 h(n) 还涉及上界锐性或更强结构定理，远比证明一个超线性下界更困难。

### 需要的验证

- 先给出等价差体表述，并检查是否覆盖所有紧凸 C 与不相交条件。
- 对任何候选构造，逐类证明所有点对的差向量相对 C-C 的位置：在外部、在距离 1 的边界上，或距离不为 1。
- 用精确有理/代数坐标而非浮点数验证小规模实例，避免数值误判。
- 证明构造可对无限多个 n 扩展，并把边数下界化为显式 n^{1+c}。
- 若使用形式化证明，应至少形式化关键凸几何引理和参数不等式，而不只是形式化最终代数计算。

### 公开版思考摘要

这个问题对 AI 的吸引力在于它有一个自然的几何-组合重写：选择 C 等价于选择一个差体障碍区，单位距离边来自该障碍区外侧距离为 1 的边界。这样可以把问题转成“设计一个凸障碍和一个点集，使许多差向量落在指定边界上，同时所有差向量避开障碍”。这类问题适合计算搜索、参数化多边形构造和形式化不等式检查。但真正的瓶颈是把搜索结果变成对所有大 n 有效的渐近构造。因此我判断 GPT-5.5 工具增强系统有现实机会显著推进或找到候选超线性族，但直接完整确定 h(n) 的概率较低。

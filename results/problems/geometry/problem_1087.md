## 原问题

Let $f(n)$ be minimal such that every set of $n$ points in $\mathbb{R}^2$ contains at most $f(n)$ many sets of four points which are 'degenerate' in the sense that some pair are the same distance apart. Estimate $f(n)$ - in particular, is it true that $f(n)\leq n^{3+o(1)}$?

- 可能路线: 可行路线是先把“退化四点集”精确定义为四点中六条两两距离存在重复，并分解为等腰三角形型、菱形/等距边型、同圆或公共垂直平分线相关的距离碰撞型计数；然后用距离能量、点圆关联、单位距离图、二分距离图 K_{2,2} 计数等工具重新表达 f(n)。模型有希望通过计算搜索极值构型、自动化检验格点/圆上点/乘积型构型，以及形式化验证组合分解与双计数引理来推进局部结果。若要接近 n^{3+o(1)}，关键会是把所有距离碰撞型统一压到接近三次方的总量，而不是只逐类得到 n^{7/2} 级别的粗界。

### 支持理由

- 题目陈述短、对象明确，适合模型把问题转化为有限的组合计数、距离图和关联几何语言。
- 已有上下界 n^3 log n << f(n) << n^{7/2} 给出可校验的基线；模型可先复现这些量级，再尝试定位损失来源。
- 目标 n^{3+o(1)} 与下界 n^3 log n 只差亚多项式/对数因子，说明猜想若真，可能需要精细化现有距离能量估计，而非完全新定义。
- 计算反例搜索和构型枚举对该题有实际价值：可测试网格、圆、同心圆、多圆、随机扰动格点等是否产生超过 n^{3+o(1)} 的退化四元组。
- 形式化证明工具可用于验证繁琐但局部的双计数分解，降低模型在组合类型分类上的错误率。

### 主要障碍

- 核心难点很可能在平面距离关联几何的尖锐估计；从 n^{7/2} 改到 n^{3+o(1)} 是实质性指数改进，不像纯粹可计算枚举问题。
- “四点退化”包含多种距离重复模式，模式之间可能重叠；容斥和过计数若处理不当，很容易得到错误上界。
- 下界已经达到 n^3 log n 量级，因此任何声称 O(n^3) 或明显更强的结论都必须解释为何不被已知构型否定。
- 只靠数值搜索无法证明普遍上界；它更适合找候选极值构型或排除朴素猜想。
- 题目尚未形式化，首先需要严格固定四点集是否要求点互异、重复距离是否指六条边中两条距离相等、以及重合/共线等边界情形如何计数。

- 对所有距离重复类型建立机器可检查的分类表，并验证每个退化四点集至少被覆盖一次、重叠项不会导致非法扣除。

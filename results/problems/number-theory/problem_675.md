## 原问题

We say that $A\subset \mathbb{N}$ has the translation property if, for every $n$, there exists some integer $t_n\geq 1$ such that, for all $1\leq a\leq n$,\[a\in A\quad\textrm{ if and only if }\quad a+t_n\in A.\]{UL}

{LI}Does the set of the sums of two squares have the translation property?{/LI}

{LI}If we partition all primes into $P\sqcup Q$, such that each set contains $\gg x/\log x$ many primes $\leq x$ for all large $x$, then can the set of integers only divisible by primes from $P$ have the translation property?{/LI}

{LI}If $A$ is the set of squarefree numbers then how fast does the minimal such $t_n$ grow? Is it true that $t_n>\exp(n^c)$ for some constant $c>0$?{/LI}

{/UL}

### 支持理由

- 该问题的定义是有限模式重现，天然适合转化为有限同余约束加筛余项估计；这类结构可被计算搜索、SAT/SMT、CRT 构造和有限验证有效辅助。
- 平方自由数部分已有备注说明翻译性质可由初等筛推出，因此模型不需要从零解决存在性，而可以集中处理最小 t_n 的增长下界、实验规律、可证下界框架和反例搜索。
- 二平方和集合有清晰的经典刻画：整数可表为二平方和当且仅当每个 3 mod 4 素因子指数为偶数；这给自动化推理提供了明确的代数入口。
- 素数划分版本虽然更难，但问题输入已经给出密度假设，模型可尝试构造极端划分、检查局部障碍、用随机/结构化划分模拟翻译性质，从而产出有价值的证据或条件性定理。
- 形式化证明方面，翻译性质本身、CRT 步骤、小 n 验证和有限筛引理可以被 Lean/Isabelle 或独立程序验证，降低了模型在组合细节上的出错风险。

### 主要障碍

- 二平方和问题中，要求同时复制属于集合和不属于集合的位置；强制不属于集合较容易，避免移位后属于集合的位置出现新的 3 mod 4 奇指数素因子较难，需要强筛估计和相关性控制。
- 素数划分问题的坏素数集合 Q 具有正密度，倒数和发散；这正好超出备注中 Brun 筛给出的稀疏互素障碍条件，常规筛法可能无法保证需要的正剩余。
- 平方自由数最小 t_n 的下界是优化型问题，不只是存在性；要证明 t_n>exp(n^c) 需要排除所有较小平移，涉及大量相关的平方整除模式和可能很强的概率/筛下界。
- 模型容易把“每个有限模式在某处出现”误判为随机序列中的显然性质，但这些集合是高度算术相关的确定性集合，独立性启发不能直接替代证明。
- 若尝试反例路线，需要证明某个前缀模式永不重现；这通常要求全局数论约束，而不是有限计算即可完成。

### 需要的验证

- 对任一声称的正解，需要明确给出如何选择 t_n，以及证明所有 1<=a<=n 的双向等价，而不仅是密度或概率启发。

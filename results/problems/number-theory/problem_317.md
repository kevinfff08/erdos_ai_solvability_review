## 原问题

Is there some constant $c>0$ such that for every $n\geq 1$ there exists some $\delta_k\in \{-1,0,1\}$ for $1\leq k\leq n$ with\[0< \left\lvert \sum_{1\leq k\leq n}\frac{\delta_k}{k}\right\rvert < \frac{c}{2^n}?\]Is it true that for sufficiently large $n$, for any $\delta_k\in \{-1,0,1\}$,\[\left\lvert \sum_{1\leq k\leq n}\frac{\delta_k}{k}\right\rvert > \frac{1}{[1,\ldots,n]}\]whenever the left-hand side is not zero?

- 可能路线: 可行路线是把问题转化为关于 L_n=[1,...,n] 下整数分子 N=\sum_{k\le n}\delta_k L_n/k 的最小非零绝对值问题；用 meet-in-the-middle、格约化、模约束和 SAT/ILP 搜索检查较大 n 的最小分子分布，并尝试证明不存在分子 ±1 的充分大 n 情形。第一问还可从 2^n 或 3^n 个子集和的间距、局部中心极限定理、平滑数/lcm 结构、以及已有弱上界的改进角度推进。形式化证明工具可用于验证等价变形、小 n 反例、搜索证书和有限区间断言。

### 支持理由

- 问题有清晰的有限组合形式：每个 n 都归结为有限个三值系数和一个整数分子，适合计算搜索、证书验证和形式化建模。
- 第一问要求 O(2^{-n}) 级别的小非零和；简单鸽巢思想给出指数级候选方向，但要控制非零、系数范围和常数，需要更精细的结构论证，模型可在这类改造上提供有效尝试。
- 第二问的非严格下界来自分母 L_n 是显然的，真正难点是排除分子等于 ±1；这类有限整数组合排除问题适合用模素数、p-adic 约束、覆盖同余与计算实验寻找模式。
- 题目已 formalized，说明至少部分表述可进入证明助手环境；GPT-5.5 级模型可用来连接手工证明、Lean/Isabelle 形式化和自动搜索证书。
- 备注中已有弱版本和启发式阶，给模型一个可对齐的理论锚点：可以尝试复现、压缩或局部增强这些论证，而非从零探索。

### 主要障碍

- 第一问的目标 2^{-n} 可能与备注中的启发式真阶相冲突；若启发式正确，则原命题可能为假，完整解决需要构造下界而非只找小和。
- lcm(1,...,n) 的素因子指数结构高度不均匀，分子 N=\sum\delta_k L_n/k 的可达集合不是随机整数集，随机模型可能误导。
- 计算搜索空间为 3^n，直接穷举很快失效；即使用 meet-in-the-middle，也需要强剪枝和可验证证书才能支持数学结论。
- 第二问要证明充分大 n 不存在分子 ±1，是无限族排除问题；有限验证只能提示阈值，不能替代理论证明。
- 已有评论已达到较弱但非平凡的上界，说明低门槛方法大概率已被尝试；模型需要真正引入新的结构或强计算证据才可能显著推进。

### 需要的验证

- 对若干 n 计算最小非零值及是否存在分子 ±1，并保存可独立校验的系数证书或不可行性证书。
- 形式化验证等价命题：所有和都可写作 N/L_n，非零时 |sum|>=1/L_n，严格失败当且仅当存在 N=±1。

- 若提出第一问证明，需要验证常数 c 与所有小 n 的兼容性，而不只是不定常的渐近上界。
- 若提出反例方向，需要给出无限多 n 的下界机制，或至少给出可验证的强计算趋势和理论外推依据。

这个问题对 AI 工具链有一定吸引力，因为它有明确的整数化、有限搜索和形式化验证入口；模型可以较可靠地生成搜索程序、验证小规模证据、发现同余结构，并尝试把已有弱上界改写成可检查的证明。但完整解决似乎需要新的数论结构理解，特别是判断最小非零 signed unit-fraction sum 的真实指数尺度，以及无限排除分子 ±1 的机制。备注中的启发式还暗示第一问可能并非简单为真，因此不能把计算发现的小和直接升格为证明。综合看，GPT-5.5 级模型较可能显著推进局部证据和证明框架，但单独完成开放问题的概率偏低。

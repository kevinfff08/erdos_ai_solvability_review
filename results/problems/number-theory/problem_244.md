### 主要障碍

- 目标是所有实数 C>1，而不是整数 C 或几乎所有 C；需要处理可能非常特殊、非随机、甚至近似构造出的 C。
- 正密度结论通常要求强而均匀的筛法控制，尤其要限制表示之间的相关性；对 floor(C^k) 的相关性估计可能很难做到全 C 一致。
- “几乎所有 C”的结果不自动给出个别 C，例外集可能包含高度结构化的值，AI 很难仅靠实验排除。
- 如果存在潜在反例，它可能表现为极慢收敛或稀有模障碍，普通有限计算很难给出决定性证据。
- 问题涉及解析数论和素数分布，形式化工具能验证推导，但通常不能自动发现关键新估计。

### 需要的验证

- 复现整数 C 的 Romanoff 情形，并确认所需常数、密度下界和筛法依赖项。

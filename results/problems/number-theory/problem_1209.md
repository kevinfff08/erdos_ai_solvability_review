## 原问题

Let $A=\{a_1<a_2<\cdots\}$ be a sequence of integers which tends to infinity sufficiently fast. If there is an $n$ such that all $n+a_k$ are primes then must there exist infinitely many such $n$?

What if we ask for $n+a_k$ to be squarefree instead of prime?

Are there $n$ such that $n+2^{2^k}$ is always a prime (or always squarefree, or infinitely often a prime, or infinitely often squarefree)?

- 题面备注已经给出一般序列素数问题的“平凡反例”：为每个 k 选素数 q_k 并令 a_k+k≡0 mod q_k，可使 n=k 时某项被 q_k 整除，从而破坏“若存在一个 n 则存在无穷多个 n”的直觉；这类构造很适合由模型配合形式化证明验证。
- 平方自由的一般问题也有相同风格的 q_k^2 同余反例，属于局部同余构造，AI 工具较容易检查没有隐藏量词错误。
- 特殊序列 n+2^{2^k} 的“总为素数”在备注中已有证明思路，涉及乘法阶为奇数以及选择 l 使 2^l≡1 mod m 后得到周期性整除；这部分很适合被 GPT-5.5 级模型重写为完整证明并做形式化校验。

### 主要障碍

- “是否存在 n 使 n+2^{2^k} 无穷多次为素数”类似对极稀疏指数序列中的素数分布作无条件证明，通常远超当前解析数论和计算搜索能力。
- “无穷多次平方自由”看似比素数弱，但仍需要控制无限多 k 上没有任何平方因子；仅靠有限搜索或局部模覆盖不能直接给出正向无穷性结论。
- 题面中“always squarefree”和“infinitely often squarefree”可能需要区分不同 n 的存在性、所有 n 的否定性、以及有限例外情形；量词结构稍复杂，容易产生伪证明。
- 给定的总为素数否定论证需要细查边界情形，例如 n 的奇偶性、小 n、p 是否可能等于某些特殊小素数，以及乘法阶论证中 m 为奇数的充分条件。
- 若要证明不存在某类 n，可能需要无限模覆盖或递归构造；若要证明存在无穷多 k，可能需要当前未有的筛法强度。

### 需要的验证

- 把一般序列素数反例写成完整量词证明：明确如何保证 a_k 严格递增、增长任意快、q_k 不整除 k，并证明除指定 n 外不会误影响“存在一个 n”的前提。
- 对平方自由反例验证 q_k^2 同余版本：确保 n+a_k 被平方整除，并处理 q_k 与 k、a_k 的相容条件。
- 形式化或半形式化检查 n+2^{2^k} 不可能总为素数的论证，特别是 n 偶数、n 奇数、小 n、p 的选择和 l 的存在性。

## 原问题

### 支持理由

- 问题有清楚的有限化形式：给定 x 后就是带权集合覆盖问题，适合计算搜索、反例搜索和形式化验证。
- 目标不是指定 residue classes，而是允许自由选择，这给启发式搜索和机器辅助发现构造留下空间。
- 总权重为 sum 1/p 的约束非常自然，可通过 LP 对偶、覆盖数、随机覆盖期望和筛论语言进行多种重述，AI 可以系统枚举这些等价框架。
- 备注中已经给出一个相关正结果：存在素数集 P 使被某些 p 整除的整数有正比例覆盖，这提示局部覆盖密度并非完全不可控，可作为构造实验的起点。
- 若能发现覆盖初始区间的自相似或分块模式，计算机可验证大量有限实例，并辅助把模式转成可证明的归纳结构。

### 主要障碍

- 从有限 x 的成功覆盖到统一常数 C 的渐近证明存在巨大鸿沟；计算搜索容易只给出偶然小规模结构。
- 每个素数只能选择一个剩余类，且总 reciprocal weight 有界，覆盖效率需要高度相关的 residue choices，普通随机选择很难直接给出完全覆盖。
- 反方向也很难：要证明任意有界权重系统都留下正比例未覆盖整数，通常会碰到强筛不等式或覆盖系统的极端例子。
- 问题处在素数、覆盖系统和稀疏模数筛法的交界，核心障碍可能是缺少正确结构定理，而不是缺少计算量。
- 形式化证明可以验证候选论证，但若没有新的数学不变量或构造机制，形式化工具本身不会显著降低难度。

### 需要的验证

- 对若干增长的 x 求解或近似求解最小总权重覆盖，记录最优/上界是否呈现有界趋势。
- 用独立求解器交叉验证有限覆盖实例，保存 primes、residue classes、覆盖证书和未覆盖集合检查。
- 检查 LP 对偶或 fractional covering lower bound 是否随 x 增长，判断计算证据支持正向还是反向。
- 若发现递归/分块构造，需要证明其总权重不随 x 发散，并给出覆盖所有 n<x 的严密归纳。
- 若提出否定性证明，需要验证其不与备注中已知正比例覆盖结果冲突，并明确常数依赖。

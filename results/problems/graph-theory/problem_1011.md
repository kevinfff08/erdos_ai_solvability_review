## 原问题

Let $f_r(n)$ be minimal such that every graph on $n$ vertices with $\geq f_r(n)$ edges and chromatic number $\geq r$ contains a triangle. Determine $f_r(n)$.

### 支持理由

- 问题定义清楚，目标函数可直接转化为有限极值优化：f_r(n) 等于相应 triangle-free、色数至少 r 的最大边数加一。
- 备注已经给出强结构线索：Simonovits 将主项与参数 g(r) 联系起来，说明问题不是完全无结构的开放题。
- 固定小 r 的情形适合工具辅助：可用 SAT/ILP 搜索极值图、验证色数约束、枚举临界构型，并为证明提供猜想。
- 已有 r=2、r=3、r=4 的精确或大 n 精确结果，暗示固定 r 推进可能沿稳定性和有限构型分析展开。
- 形式化证明工具可用于验证图论归约、边界情况和计算证书，降低复杂构型证明中的错误风险。

### 主要障碍

- 总体“Determine f_r(n)”覆盖所有 r 和 n，范围很大，精确答案很可能依赖高色数三角形自由图的细致结构。
- g(r) 与 triangle-free 高色数图、Ramsey 型界和删除到二分图的距离相关，备注中的渐近界仍留有常数级差距，这会限制全局精确解。
- 即使搜索找到候选极值图，也需要人类级稳定性证明把有限证据提升为所有大 n 或所有 n 的定理。
- 色数约束和三角形自由约束组合后搜索空间增长很快，计算验证容易只覆盖小 n 或小 r。
- 问题目前未形式化，现成的机器可检验证明基础可能不足，需要先建立图论定义、阈值定义和极值归约。

### 需要的验证

- 先严格验证 f_r(n) 与 triangle-free、chi(G)>=r 的最大边数之间的等价转化及所有边界情形。
- 为固定 r 生成可复现的 SAT/ILP 证书：无三角形、色数下界、边数最优性或反例。
- 对 r=4 的已知公式做复现性检查，确认工具链能重新发现或验证 n>=150 的极值模式。
- 对候选 r=5 或一般 r 的构型，需要独立证明其 triangle-free、色数至少 r、边数达到猜测下界。
- 任何渐近推进都要验证与给定备注中的 g(r) 关系一致，并明确 O(1) 项或适用的 n,r 范围。

### 公开版思考摘要

这个问题对 AI 的吸引力在于它有明确的有限优化形式、已知低阶结果和一个连接到 g(r) 的结构性框架，因此工具型模型能做的不只是泛泛讨论，而是可以搜索极值图、产生证书、形式化归约并复核固定 r 的猜想。主要风险是完整问题过宽，且核心参数牵涉高色数三角形自由图的深层结构；因此更现实的评价是“可能显著推进局部情形或验证候选定理”，而不是“高概率完全解决”。

## 原问题

Let $l(n)$ be maximal such that if $A\subset\mathbb{Z}$ with $\lvert A\rvert=n$ then there exists a sum-free $B\subseteq A$ with $\lvert B\rvert \geq l(n)$ - that is, $B$ is such that there are no solutions to\[a_1=a_2+\cdots+a_r\]with $a_i\in B$ all distinct.

Estimate $l(n)$. In particular, is it true that $l(n)n^{-1/2}\to \infty$? Is it true that $l(n)< n^{1-c}$ for some $c>0$?

### 支持理由

- 题目是清晰的有限组合极值问题，适合被转化为超图独立数问题：顶点为 A，边为满足 a1=a2+...+ar 的 distinct 元组；工具化模型可以系统检查独立集下界、上界构造和小规模极值。
- 给定备注已经提供非平凡历史进展：下界达到 sqrt(n log n/loglog n) 量级，上界达到 n/log n。模型可从这些锚点出发做证明重建、常数/对数因子检查和形式化验证，而不是从零开始。
- 第一个子问题 l(n)n^{-1/2}->infty 在备注给出的 CKS 下界下看起来已经得到肯定答案；模型可以较可靠地识别并审计这一逻辑关系。
- 该问题与现代工具匹配度较高：超图容器、概率方法、贪心/随机筛选、有限域或模数嵌入、SAT/ILP 反例搜索都能提供可验证的推进证据。
- 目标不是完整求解时，GPT-5.5 级模型很可能能产出有价值成果：统一符号、重证已知界、发现小 n 数据、提出可检验构造、定位现有证明中的可改进瓶颈。

### 主要障碍

- 核心开放部分要求显著缩小 sqrt(n log n/loglog n) 与 n/log n 之间的巨大差距，尤其是证明 l(n)<n^{1-c}，这比当前备注中的上界强很多。
- 约束允许任意长度 r 的 distinct 求和关系，导致对应超图非均匀且边阶数可变，标准固定均匀超图工具不能直接套用。
- 最坏集合 A 可以有高度非随机、层级化或稀疏加性结构；计算搜索的小 n 结构未必能外推到渐近构造。
- 若 CKS 猜想 l(n)>=n^{1-o(1)} 为真，则多项式节省上界问题的答案是否定的；模型必须同时处理相互竞争的启发式，不能单线推进。
- 需要文献级严谨性：题中备注引用的历史论证可能有细节困难或术语差异，自动重建证明很容易遗漏 distinct 条件、r 的范围或整数到模结构的转移损失。

### 需要的验证

- 逐条形式化定义：明确 r 的允许范围、a_i 是否必须全部属于 B 且两两 distinct、是否允许负数和零，以及这些选择是否影响已有界。
- 审计备注中的 CKS 下界是否确实直接推出 l(n)n^{-1/2}->infty，并检查隐含常数与渐近条件。
- 用独立实现的 SAT/ILP/最大独立集程序计算小 n 或特殊 A 的精确/近似 l_A 值，避免只依赖模型生成的样本。
- 对任何候选上界构造，必须证明对所有大小超过目标阈值的 B 都含有一条允许的求和关系；计算验证只能作为有限证据。
- 对任何候选下界证明，需用 Lean/Isabelle 或至少机器检查的概率不等式与超图参数推导验证，防止对非均匀边和 distinct 条件处理错误。

## 原问题

Let $A=\{a_1<a_2<\cdots\}\subset \mathbb{N}$ be an infinite set such that the sets\[S_r = \{ a_1+\cdots +a_r : a_1<\cdots<a_r\in A\}\]are disjoint for distinct $r\geq 1$. How fast can such a sequence grow? How small can $a_{n+1}-a_n$ be? In particular, for which $c$ is it possible that $a_{n+1}-a_n\leq n^{c}$?

### 支持理由

- 问题陈述短，核心约束可以转化为有限子集和碰撞禁避，适合模型配合 SAT/SMT、整数规划、贪心搜索和证明检查器进行实验。
- 目标包含多个层级：即使不能确定最优增长，也可以显著推进构造、反例搜索、有限范围边界和非最优指数界。
- 该条件只区分不同子集大小的和，而不要求同大小子集和唯一，因此比 Sidon/B_h 型完全唯一性更有可利用结构，模型可能发现较稠密构造。
- 形式化验证门槛相对清晰：给定有限前缀或递推构造后，可以把所有坏关系归约为有界的 signed subset relation 检查。

### 主要障碍

- 核心问题询问“多快增长”和“哪些 c 可行”，这通常要求接近最优的无限构造与反向密度界，远超单纯计算搜索。
- 有限前缀无碰撞不容易外推到无限序列；搜索得到的低间隔模式可能只是有限伪结构。
- 若要证明 a_{n+1}-a_n <= n^c 的无限构造，需要强控制所有未来跨长度子和碰撞，归纳条件可能迅速膨胀。
- 下界方向可能需要深的 additive combinatorics 工具，而模型容易给出看似合理但量词或依赖关系不严密的证明。

### 需要的验证

- 验证条件等价化是否严格：特别是公共元素消去后，剩余 signed relation 的系数和是否准确对应不同 r 的碰撞。
- 对任何提出的构造，必须给出无限证明，而不只是有限搜索；有限证书只能作为证据或辅助。
- 若声称某个 c 可行，需要明确常数、起始 n、递推定义，以及对所有不同 r,s 的全局无交证明。
- 若声称不可行或给出下界，需要检查是否只排除了更强条件，例如同大小子和唯一，而不是本题较弱条件。

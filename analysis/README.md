# Analysis reference

This directory documents how the published results were defined and checked.

- `methodology.md`: evidence policy, status taxonomy, scoring and prompt construction.
- `deep_review_protocol.md`: the frozen V2 review contract supplied to the reviewing model.
- `deep_review.schema.json`: schema for canonical V2 review JSON.
- `code/`: a small reference sample showing the single-problem review implementation.

The repository is intended to share results rather than operate a review service. Code here is retained for methodological transparency only; batch runners, logs, checkpoints and maintenance utilities are not part of the published interface.

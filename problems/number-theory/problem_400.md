## 原问题

For any $k\geq 2$ let $g_k(n)$ denote the maximum value of\[(a_1+\cdots+a_k)-n\]where $a_1,\ldots,a_k$ are integers such that $a_1!\cdots a_k! \mid n!$. Can one show that\[\sum_{n\leq x}g_k(n) \sim c_k x\log x\]for some constant $c_k$? Is it true that there is a constant $c_k$ such that for almost all $n<x$ we have\[g_k(n)=c_k\log x+o(\log x)?\]

### 支持理由

- 问题已经形式化，核心定义清楚，适合转化为可检查的整数规划和素数赋值约束。
- Erdos-Graham 已给出 g_k(n) <<_k log n 的背景信息，说明目标量级已知，AI 可以集中在最佳常数和平均分布，而不是先建立粗阶。
- 固定 k 的计算实验可行：对 n 和候选 a_i 的搜索空间因 O_k(log n) 超额界而显著缩小，可用于发现模式、反例或候选 c_k。
- 该问题有较强的验证结构：任何候选最优元组都可由素数赋值逐项验证，适合形式化证明和自动反例搜索。

### 主要障碍

- 从逐点最大化问题过渡到平均渐近需要理解最优 a_i 的全局结构，这可能比单纯验证候选解困难得多。

- almost all 版本比平均版本更强，需要控制例外集合和波动，可能需要精细的分布估计。

## 原问题

Suppose $A\subseteq \{1,\ldots,N\}$ is such that if $a,b\in A$ and $a\neq b$ then $a+b\nmid ab$. Can $A$ be 'substantially more' than the odd numbers?

What if $a,b\in A$ with $a\neq b$ implies $a+b\nmid 2ab$? Must $\lvert A\rvert=o(N)$?

- 可能路线: 把两问统一为 k=1,2 的显式 divisibility graph。若 a=dx,b=dy 且 gcd(x,y)=1，则 k=1 情形等价于 x+y 整除 d；k=2 情形等价于 x+y 整除 2d。由此可生成所有禁边，再用最大独立集、SAT/ILP 和构造搜索分析小到中等 N 的极值结构。解析方向上，可按 gcd、比例 x:y、2-adic valuation 和 residue classes 分层，尝试把正密度集合强迫出某个参数族禁边；若失败，则反向寻找稳定的正密度独立构造。

### 支持理由

- 问题有清楚的算术参数化入口，不是完全无结构的开放题；这对模型加工具很有利。
- 第一问已有奇数集合给出约 N/2 的自然下界，且题面给出一个粗上界阈值，说明存在可攻击的密度间隙。
- 禁边可精确枚举，适合用程序交叉验证直接 divisibility 条件、参数化生成器和极值搜索。
- OEIS 标记暗示已有有限数据序列可作为计算复核对象，但本评审只依据给定 JSON 判断，不依赖外部序列内容。
- 与单位分数的等价关系提供了可检索的数学语境，可能引入已有的 divisor graph 或 Egyptian fraction 技术。

### 主要障碍

- “substantially more”不是严格数学量词；需要先把第一问转成例如是否存在 |A|>(1/2+c)N 的形式。
- 有限 N 的最大独立集数据可能强烈误导，不能直接推出渐近密度结论。
- 第二问要求证明是否必须 o(N)，这比改进常数更硬，可能需要密度增量、图容器或筛法级别的全局论证。
- 禁边图虽然显式但较稀疏且非随机，普通平均度或局部删除论证通常不足以决定线性密度是否存在。
- 目前没有形式化版本；任何 AI 生成的渐近证明都需要特别严格地检查量词、误差项和边界情形。

### 需要的验证

- 实现两个独立禁边生成器：一个直接测试 a+b | kab，另一个使用 gcd 参数化，并在大范围 N 上互相校验。
- 用 SAT/ILP/branch-and-bound 计算小 N 的最大独立集，同时保存可复核证书或可重放脚本。
- 系统搜索 residue class、2-adic 层、区间层和按最大素因子筛选的候选构造，估计是否可能超过奇数集合的密度。
- 对任何声称的上界证明，形式化核心整除引理，并用 proof assistant 或独立审稿脚本检查有限例外。
- 对第二问，必须验证正密度假设下禁边计数不是仅在平均意义成立，而是真能强迫同一集合内部出现一条禁边。

## 原问题

- 信心: `medium`
- 可能路线: 较现实的路线是先定义 M(n,k)=不超过 n 的最大二项式系数除数，并用精确 p-adic 分解和分支限界搜索估计 inf M(n,k)/n 的经验下界；同时把问题按 k 与 n 的相对大小分区。Faulkner 型大素因子结果可覆盖部分 k 与 n 同阶的区域，剩余难点集中在 k 远小于 n 或过渡区域。若走正解路线，需要把经验下界转化为关于连续整数乘积和分母 k! 抵消后的统一除数组合引理。若走负解路线，需要搜索并证明无限族，使得每个 d∈(cn,n] 都不整除 binomial(n,k)。

### 支持理由

- 问题表述初等，核心对象是 binomial(n,k) 的整除结构，适合用精确整数分解、p-adic 估值、除数搜索和形式化证明工具共同推进。
- 给定信息显示该问题已有可用 foothold：总能在 [n/k,n] 找到除数，Faulkner 型结果给出某些范围内的大素因子，这有利于模型做分区证明而不是从零开始。
- formalized=yes 表明至少问题陈述或相关基础可进入形式化环境，模型可把候选引理、有限例外和计算验证做成可审计产物。
- 反例搜索也有明确计算目标：对给定 n,k 枚举或优化所有不超过 n 的除数，寻找 M(n,k)/n 很小的样本，并尝试拟合参数族。

### 主要障碍

- 绝对常数 c 要对所有 1≤k<n 同时成立，已有的 [n/k,n] 下界在 k 增大时不能给出固定比例。
- 证明存在除数落在 (cn,n] 比证明存在大素因子更复杂，因为可用除数可能是多个素因子的组合，必须控制复合除数结构。
- 若要否定命题，不能只证明没有大素因子或没有接近 n 的除数，而要排除整个线性区间内所有整数整除 binomial(n,k)。
- 从有限搜索到无限证明的跳跃很大；搜索可能发现极端样本，但把样本提升为参数化构造通常需要较深的数论结构。
- 给定备注中已有正反方向的历史线索，说明该问题可能处在简单实验和现有标准定理都不足以直接解决的区域。

### 需要的验证

- 实现精确搜索：用素因子估值计算 binomial(n,k)，再求最大 d≤n 且 d|binomial(n,k)，记录 M(n,k)/n 的低值样本。
- 对不同区域分别验证：固定小 k、k=o(n)、k≈αn、n-k 小等，不应只依赖随机样本。
- 若模型提出正解，需要形式化检查关键整除引理、区间覆盖和所有有限例外，尤其要确认常数 c 不依赖于 k 或 n。
- 若模型提出负解，需要给出无限族，并证明对任意给定 c 或某个趋零比例，区间 (cn,n] 中每个整数都不整除相应二项式系数。
- 需要独立复核所有引用的外部数论定理适用条件，例如素数区间、最小大于 2k 的素数、以及例外情形。

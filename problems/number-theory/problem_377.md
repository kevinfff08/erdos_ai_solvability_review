### 主要障碍

- 核心难点是需要对依赖 n 的素数集合给出最坏情形的全局控制；平均几乎处处结果并不能排除稀有 n 造成无界增长。
- 条件 p 不整除等价于多层 p 进数字限制，不同素数之间高度相关，普通 Mertens 估计只能给出 log log n 级别。
- 若要证明绝对有界，必须排除精心构造的 n 同时满足许多素数的无进位条件，这接近深层筛法或同余构造问题。
- 大素数区间虽然较可处理，但中小素数的累积 1/p 权重仍可能产生主要障碍。
- 备注中的已有 c log log n 上界离常数界仍有本质差距，单纯优化常数不够，需要新的结构性论证。

### 需要的验证

- 先形式化并验证判据：p 不整除 binom(2n,n) 当且仅当对所有 j>=1 有 floor(2n/p^j)-2floor(n/p^j)=0，或等价 p 进制无进位。

## 原问题

Let $f:\mathbb{N}\to \mathbb{R}$ be an additive function (i.e. $f(ab)=f(a)+f(b)$ whenever $(a,b)=1$). Let\[A=\{ n \geq 1: f(n+1)< f(n)\}.\]If $\lvert A\cap [1,X]\rvert =o(X)$ then must $f(n)=c\log n$ for some $c\in \mathbb{R}$?

### 支持理由

- 题目陈述短，结构清晰，适合模型把问题拆成 additive function 的素数幂参数、相邻整数互素性、异常集密度三部分来处理。
- 已有结果给出明确锚点：A 为空、差分 o(1)、以及更强稀疏条件加技术性大值限制下结论成立。这些边界条件有利于工具辅助复现和寻找可推广环节。
- 计算和反例搜索有实际价值：可以随机指定 f(p^k)，统计 f(n+1)<f(n) 的密度趋势，用来发现非对数型函数是否天然产生正密度下降。
- 形式化证明工具可能帮助验证一些基础稳定性命题，例如若 f 在素数上偏离 c log p 的集合足够大，则下降集应有正密度。
- 该问题不依赖庞大对象分类或复杂几何结构，若有突破，可能来自可局部验证的解析数论引理链，适合模型辅助提出和检验中间命题。

### 主要障碍

- 从 |A∩[1,X]|=o(X) 推到强结构结论非常弱；密度零允许异常集远比已知部分进展中的 X/(log X)^{2+c} 大。
- additive function 可在素数幂上有很不规则甚至很大的取值，缺少大值控制会让截断和平均化论证困难。
- 相邻整数 n,n+1 的素因子结构强相关于局部差分，但 f 是按互素乘法加法定义，证明需要同时控制两侧素因子贡献。
- 反例搜索只能给启发，不能排除高度稀疏或精心构造的 pathological additive functions。
- 题目要求精确刚性结论 f(n)=c log n，而不是近似结论；从统计性单调到点态完全确定存在明显最后一公里难度。

### 需要的验证

- 复现 Erdős 在 A 为空和 f(n+1)-f(n)=o(1) 情形下的证明，明确哪些步骤可能接受密度零异常。
- 复现 Mangerel 的部分结果框架，并标记“稀疏下降集”和“大值控制”分别在哪里被使用。
- 构建计算实验：对多类非对数 additive function 估计下降集密度，尤其测试大素数赋值、稀疏扰动、强振荡赋值和素数幂异常。
- 提出并验证中间命题：若 f(p)-c log p 在正密度或足够多素数上偏离，则 A 应有正密度。
- 若模型给出证明，需由人工专家检查解析数论估计、极限交换、异常集处理和对无界 f(p^k) 的覆盖。

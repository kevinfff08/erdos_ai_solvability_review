## 原问题

Let $F(k)$ be the minimal $N$ such that if we two-colour $\{1,\ldots,N\}$ there is a set $A$ of size $k$ such that all subset sums $\sum_{a\in S}a$ (for $\emptyset\neq S\subseteq A$) are monochromatic. Estimate $F(k)$.

### 支持理由

- 问题陈述短、对象明确：二染色区间、寻找 k 元集合 A，使所有非空子集和同色，适合转化为有限超图 Ramsey/约束满足问题。
- 备注已经给出存在性来源和两个下界规模，说明有清晰的基准结果，模型可以围绕这些基准做复核、变体搜索和证据生成。
- 计算工具能直接处理小 k：枚举或 SAT 编码可以寻找避免单色 finite-sums 配置的染色，从而给出小规模证书或反例，帮助发现模式。
- 形式化证明工具可用于验证有限证书、基本归约、概率估计中的组合计数，降低错误率。
- 该问题横跨加性组合与 Ramsey 理论，LLM 可辅助整合概率方法、超图独立集、随机构造等证明模板，可能显著推进某个局部界而非完整解决。

### 主要障碍

- 核心目标是估计 F(k) 的渐近增长，而已给下界已经非常强；进一步改进可能需要新的结构性思想，不只是更大规模计算。
- 有限搜索很快遭遇组合爆炸，小 k 模式未必能外推到渐近下界或上界。
- 上界来自深层 Ramsey/Rado/Folkman 型存在定理，显式化或优化常数与塔高可能技术复杂。
- 要证明随机构造有效，需要精确控制大量相关的 subset-sum 配置，依赖性强，简单一阶矩或 union bound 可能不足。
- 问题要求所有非空子集和同色，配置数量为 2^k-1，且不同 A 之间高度重叠，自动猜想容易产生不可推广或不可证明的模式。

### 需要的验证

- 对小 k 的 SAT/ILP 结果需要可复查证书：不可满足证明、染色表、或独立验证脚本。

- 需要复核备注中 Erdős-Spencer 与 Balogh-Eberhard-Narayanan-Treglown-Wagner 下界的适用形式，确保没有误用常数、底数或 k 的范围。

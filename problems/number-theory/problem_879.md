## 原问题

Call a set $S\subseteq \{1,\ldots,n\}$ admissible if $(a,b)=1$ for all $a\neq b\in S$. Let\[G(n) = \max_{S\subseteq \{1,\ldots,n\}} \sum_{a\in S}a\]and\[H(n)=\sum_{p<n}p+ n\pi(n^{1/2}).\]Is it true that\[G(n) >H(n)-n^{1+o(1)}?\]Is it true that, for every $k\geq 2$, if $n$ is sufficiently large then the admissible set which maximises $G(n)$ contains at least one integer with at least $k$ prime factors?

### 支持理由

- 问题有清晰的组合优化表述：顶点为 1 到 n，边表示 gcd 大于 1，目标为最大权独立集；这适合用 MILP、SAT/MaxSAT、分支定界和证书验证来做反例搜索与结构发现。

### 主要障碍

- 备注明确说 Erdős 和 Van Lint 的 n^{1+o(1)} 下界依赖关于素数分布的“plausible but hopeless”假设，这强烈表明核心瓶颈接近深层解析数论，而不是单纯计算优化。
- 目标误差从 n^{3/2-o(1)} 降到 n^{1+o(1)} 很大，可能需要控制大量接近 n 的合数与其素因子之间的全局匹配/覆盖，而现有通用素数分布工具可能不足。
- 最大权独立集的精确计算随 n 增长很快变难；计算实验只能验证有限范围，很难直接支撑渐近结论。
- 第二问要求对每个固定 k 证明最优集合最终包含至少 k 个素因子的整数，随着 k 增大需要处理越来越复杂的素因子冲突和交换模式。

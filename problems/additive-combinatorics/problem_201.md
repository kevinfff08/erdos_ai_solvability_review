## 原问题

Let $G_k(N)$ be such that any set of $N$ integers contains a subset of size at least $G_k(N)$ which does not contain a $k$-term arithmetic progression. Determine the size of $G_k(N)$. How does it relate to $R_k(N)$, the size of the largest subset of $\{1,\ldots,N\}$ without a $k$-term arithmetic progression? Is it true that\[\lim_{N\to \infty}\frac{R_3(N)}{G_3(N)}=1?\]

### 支持理由

- 问题定义清晰，适合转化为有限超图独立数问题；给定任意 N 点整数集，其 k 项等差数列形成超边，G_k(N) 是所有这类超图独立数的最小值。
- 小规模实例可由计算工具系统搜索，尤其可验证摘录中的 G_3(5)=3、R_3(5)=4、G_3(14)<=7、R_3(14)=8 一类现象，并可能发现新的极值构造模式。
- 已有摘录给出非平凡比较 R_k(N) <<_k G_k(N)，说明问题不是完全孤立的猜想；AI 可围绕该比较定理尝试定量改进、特殊化到 k=3、或提取可形式化的中间引理。
- 目标极限为 1 是渐近精细问题，可能通过结构定理、容器方法、稠密模型、Freiman 型压缩或随机模型启发来获得局部推进；这些方向适合模型配合文献检索和证明检查生成可验证候选命题。

### 主要障碍

- 从常数因子比较 R_k(N) <<_k G_k(N) 提升到 R_3(N)/G_3(N) -> 1 需要非常强的渐近稳定性，而给定摘录没有显示现有技术已接近这一精度。
- G_k(N) 对所有 N 个整数集合取最坏情形；极值集合不一定类似区间，可能有复杂的尺度结构，使得简单压缩或归一化会破坏等差关系。
- R_3(N) 本身也是深层加性组合对象，其精确阶和常数级行为很难；若要比较到 1+o(1)，会受到区间无 3-AP 集合精细结构未知性的限制。
- 有限搜索只能支持猜想或找到反例模式，不能直接覆盖渐近极限；同时极值整数集的坐标范围原则上无界，需要证明可有限化后搜索才可靠。

### 需要的验证

- 建立严格的有限化框架：证明计算搜索某个坐标范围或规范形足以代表 N 点整数集的最坏情形，否则小 N 计算只能作为启发。
- 对任何声称改进 R_k(N) 与 G_k(N) 关系的证明，需形式化检查定义量词顺序、压缩步骤是否保持或单调影响 k-AP-free 子集规模。
- 若提出极限为 1 的证明路线，必须验证误差项是 o(R_3(N)) 级别，而不是仅给出常数因子或低阶对数因子控制。
- 若提出反例路线，需要构造一族 N 点整数集并给出上界证明，显示其最大 3-AP-free 子集比 R_3(N) 渐近更小。

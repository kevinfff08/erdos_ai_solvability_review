## 原问题

Let $A=\{1\leq a_1<a_2<\cdots\}$ and $B=\{1\leq b_1<b_2<\cdots\}$ be sets of integers with $a_n/b_n\to 1$.

If $A+B$ contains all sufficiently large positive integers then is it true that $\limsup 1_A\ast 1_B(n)=\infty$?

- 反例搜索和有限截断实验可以较系统地探索有界表示数与渐近覆盖之间的张力，帮助发现候选引理或排除简单构造。

### 主要障碍

- 原命题包含 A=B 的重要特例：若 A+A 含有所有充分大整数，则表示函数是否无界。这与经典 Erdős-Turán 型问题高度相关，因此完整解决难度很高。
- 已知唯一表示型构造说明没有 A 与 B 的接近条件时命题为假；证明必须真正利用 a_n/b_n -> 1，而不是仅依赖 A+B 渐近覆盖。
- 渐近覆盖是全局条件，而表示数有界是局部上界条件；两者之间缺少直接的紧致性或有限反例证书。
- 计算搜索只能覆盖有限前缀，难以证明不存在无限稀疏且高度调控的反例。
- 形式化系统可以验证候选证明，但很难自动发现所需的新加性组合学核心思想。

### 需要的验证

- 确认 A=B 特例的精确归约：卷积计数是否与通常无序表示函数只差常数或因子，从而确立问题至少具有经典二阶基问题的难度。
- 对任何候选证明，需要形式化检查极限条件 a_n/b_n -> 1 与计数函数 A(x), B(x) 的转换是否有效。
- 构建有限搜索：在给定 N、表示数上界 K、覆盖区间 [N0,N]、以及枚举接近约束下寻找近似反例，用 SAT/ILP/CP-SAT 检查小规模障碍。
- 检验弱化定理：在正密度、定期结构、间隙上界、regular variation、或 A 与 B 对称差较小等附加假设下是否可证明 limsup 无界。
- 若声称完整解决，应由独立专家审阅，并在 Lean/Isabelle 等系统中至少形式化关键计数引理和极限转换。

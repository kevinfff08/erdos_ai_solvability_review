## 原问题

Let $A\subset\mathbb{R}^2$ be an infinite set which contains no three points on a line and no four points on a circle. Consider the graph with vertices the points in $A$, where two vertices are joined by an edge if and only if they are an integer distance apart.

How large can the chromatic number and clique number of this graph be? In particular, can the chromatic number be infinite?

### 支持理由

- 问题有明显的有限可验证部分：任意给定点集可以用精确距离、行列式共线判据、圆判据和图着色证书进行机器验证。
- clique 问题可转化为有限整数距离点集的构造与排除搜索，适合计算枚举、代数约束求解和证书化验证。
- chromatic number 的无限性若成立，通常可通过构造色数无界的有限子图族来推进；模型可以帮助设计 gadget、自动搜索小型高色数例子，并验证其几何非退化条件。
- 题目备注已经给出无限完全图不可能这一关键边界，因此 AI 可把精力集中在有限 clique 上界/下界和无限色数机制，而不是误判为需要寻找无限 clique。
- 无三点共线、无四点共圆是代数不等式约束，适合由计算工具排除退化情况，也适合把候选构造转成可审计证书。

### 主要障碍

- 完整解决色数是否可无限需要无限族构造或统一有限着色上界；有限搜索只能给下界，不能自动证明无界。
- 整数距离约束在平面中高度刚性，新增顶点若要同时满足多个整数距离邻接，几何自由度很快耗尽。
- 避免额外整数距离边、三点共线、四点共圆会使构造验证比普通单位距离图或抽象图着色更复杂。
- 若目标是最优 clique number，需要证明不存在更大有限整数距离一般位置点集，这类全局排除通常需要深的数论和计算几何结合。
- 文献检索可定位相关已知结果，但题目当前状态为 open，模型不能仅靠汇总文献给出可靠闭合答案。

### 需要的验证

- 对任何候选点集，必须用精确代数或有理数计算验证所有整数距离边、非整数非边，以及无三点共线、无四点共圆。
- 对任何色数下界，必须给出独立可检查的图着色不可行证书，例如 SAT UNSAT 证书或可复现的穷举验证。
- 若声称色数无限，必须给出参数化构造，并证明每个规模都满足几何限制且色数随参数无界。
- 若声称存在有限上界，必须证明所有满足条件的无限点集对应图都可被统一有限着色，而不仅是已搜索规模内成立。
- 需要形式化或半形式化地分离已验证结论、计算猜想和启发式搜索结果，避免把实验下界误写成定理。

### 公开版思考摘要

这个问题对 AI 的吸引力在于它有很多可机器检查的有限证书：距离、共线、共圆、clique 和图着色下界都能被精确验证。因此 GPT-5.5 可望在构造搜索、证书生成、文献定位和形式化核查上产生实质帮助。核心困难在于题目真正询问的是全局最大性和可能的无限色数；这需要从有限样例跃迁到无限族或统一结构定理。当前更现实的目标是获得新的有限高色数例子、改进 clique 下界或建立若干受限情形的上界，而不是期待模型一次性解决完整开放问题。

## 原问题

For a graph $G$ let $\tau(G)$ denote the minimal number of vertices that include at least one from each maximal clique of $G$ (sometimes called the clique transversal number).

Is it true that if all maximal cliques in $G$ have at least $cn$ vertices then $\tau(G)=o_c(n)$?

Similarly, estimate for $c>0$ the minimal $k_c(n)$ such that if every maximal clique in $G$ has at least $k_c(n)$ vertices then $\tau(G)<(1-c)n$.

### 支持理由

- 问题定义清楚，核心参数 tau(G) 可算法化：给定图可枚举极大团并求最小 hitting set，因此小规模反例搜索和极值样本生成比较直接。
- 已给备注中存在明显上下界缺口：下界约为 n^{c'/log log n}，上界形式为 tau(G) <= n-(kn)^{1/2}，这给模型提供了可推进的定量目标，而不必一次解决主问题。
- 极大团条件很强，不是任意超图横截问题；这种结构约束可能允许 AI 借助搜索发现可概括的图族或证明局部结构定理。
- Bollobas-Erdos 型阈值结果说明在接近 n 的团大小区域问题已有精确结构，模型可能沿着稳定性或阈值推广方向得到有限但有价值的改进。
- 该问题适合工具增强：SAT/MILP 用于构造，Lean/Isabelle 可用于验证组合恒等式或归纳证明，文献检索可定位 clique transversal 与 maximal clique transversal 的相关技术。

### 主要障碍

- 主问题是长期开放的极值图论问题，可能需要新的全局结构洞察，而不仅是局部搜索或标准概率法。
- 极大团枚举在最坏情况下指数级，计算搜索只能覆盖较小 n；从小规模样本外推到渐近 o_c(n) 风险很高。
- “所有极大团都很大”与“横截数大”之间存在复杂的可实现性约束，简单超图 hitting-set 直觉可能产生不可由图实现的伪反例。
- 第二问要求估计 k_c(n)，现有上下界跨度很大；即使改进其中一边，也未必接近真实阶。
- 形式化证明系统对发现新极值构造帮助有限，主要价值在检验而非创造。

### 需要的验证

- 实现独立程序：枚举或优化小 n 图，计算全部极大团和 tau(G)，确认搜索出的候选图确实满足“极大团”而不是任意大团条件。
- 对任何 AI 提出的构造，必须证明其极大团全集被完全刻画，并严格计算 clique transversal number。
- 对任何上界证明，需检查 c 与 n 的量词顺序，确认 o_c(n) 是固定 c 下成立，而不是隐含常数随 n 漂移。
- 若声称改进 k_c(n)，需要明确是上界、下界还是特定 c 区间，并与题中给出的两条已知界逐项比较。
- 建议用形式化或至少机器可检验脚本验证有限例、归纳基、关键不等式和参数范围。

这个问题不像纯概念性猜想那样完全不可计算：tau(G) 和极大团条件都能被程序检查，且备注给出可攻击的上下界差距。因此 GPT-5.5 配合搜索和证明检查，有机会发现结构化构造、改进局部界或验证一类图的结论。但主命题要求固定正比例极大团时得到次线性横截数，属于高难度渐近极值问题，完整解决概率不高。综合判断，它更适合作为“显著推进/验证候选”，而不是“高概率完整求解候选”。

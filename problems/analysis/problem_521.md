## 原问题

### 支持理由

- 问题已有强先验结构：Erdos-Offord 给出了期望量级和常数，Do24 已证明 [-1,1] 内的几乎处处极限为 1/pi。
- 全实轴常数 2/pi 与区间内常数 1/pi 的关系非常明确，提示剩余难点可能集中在倒数变换和外部根贡献，而不是完全未知的新渐近机制。
- 随机 ±1 多项式的实根问题已有成熟工具链，包括 Kac-Rice 型估计、Littlewood-Offord 反集中、局部极限定理、根计数分块、矩估计和 Borel-Cantelli 升级。
- GPT-5.5 级别模型适合做证明审计：追踪已知定理的适用条件、找出从分布对称到几乎处处结论之间的缺口，并生成需要验证的引理清单。
- 计算实验可以有效检查外部区间根数是否与内部根数同阶同常数，并帮助定位异常区间或边界效应。

### 主要障碍

- 最大障碍是几乎处处结论不能仅由每个 n 的分布对称性推出；倒序系数随 n 改变，可能需要重新建立强概率误差界。
- Do24 的 [-1,1] 定理是否已经含有足够强的概率尾界、子序列控制或可迁移的分块论证，需要逐条审查。
- 外部区间 |x|>1 经 x -> 1/x 映到内部区间，但同一多项式族的依赖结构和端点附近行为可能引入非平凡误差。
- 边界点 x=1 和 x=-1 可能出现根，虽然通常应为低阶项，但在严格几乎处处极限中仍需单独处理。
- 若已有证明高度依赖系数顺序或自然 filtration，AI 很难在没有新概率创新的情况下直接闭合证明。

### 需要的验证

- 检索并核验 Do24 的精确定理陈述：是否只证明 [-1,1]，误差形式是什么，是否有可求和的尾概率。
- 证明或反驳一个关键转移引理：外部根数 R_n((-∞,-1]∪[1,∞)) 与倒序多项式在 [-1,1] 的根数之间是否能在同一概率空间下给出几乎处处渐近 1/pi log n。
- 检查 x=±1、x=0、重根和倒数变换端点是否只贡献 o(log n)。
- 用独立实现的大规模模拟估计 R_n、R_n[-1,1] 和外部根数随 log n 的比例，并检查收敛速度与异常样本。
- 若尝试形式化证明，应先形式化根反演、边界项和概率空间中的倒序数组，再逐步接入已有概率估计。

### 公开版思考摘要

这个问题不是从零开始的开放随机多项式问题。给定材料已经提供了期望渐近和区间 [-1,1] 的几乎处处结果，因此 AI 最有价值的工作是审计并补齐“内部一半 + 外部一半 = 全实轴”的证明链。看似自然的反演对称并不自动给出同一个无限随机序列上的几乎处处极限，这是主要数学风险。如果 Do24 的方法含有足够强的可求和概率误差，GPT-5.5 配合工具有可能把证明闭合；如果没有，则可能仍需要新的强依赖控制思想。

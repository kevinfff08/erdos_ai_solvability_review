## 原问题

Let $X$ be a finite set of size $n$ and $H(n)$ be such that there is a function $f:\{A : A\subseteq X\}\to X$ so that for every $Y\subseteq X$ with $\lvert Y\rvert \geq H(n)$ we have\[\{ f(A) : A\subseteq Y\}=X.\]Prove that\[H(n)-\log_2 n \to \infty.\]

### 主要障碍

- 原命题要求从常数级改进提升到任意发散改进，通常需要能随 n 累积的结构信息；这比证明 k+1 或固定常数提升困难得多。
- f 是从整个布尔立方体到 X 的任意函数，缺乏单调性、线性、均匀性等可直接利用的结构，常规概率法可能只给出常数级亏损。
- 已知上界距离目标仅 O(log log n)，说明可能存在非常精细的近最优构造；任何下界证明必须避开这些构造。
- 有限搜索规模会很快爆炸，因为变量数量约为 n·2^n 或颜色划分布尔立方体，计算证据很难直接外推。

### 需要的验证

- 首先形式化 H(n) 的精确定义：它是存在某个 f 时满足性质的最小阈值，还是满足存在性的某个阈值函数；避免量词误读。

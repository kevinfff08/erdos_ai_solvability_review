## 原问题

Let $A\subset \mathbb{R}^2$ be a set of size $n$ and let $\{d_1,\ldots,d_k\}$ be the set of distinct distances determined by $A$. Let $f(d)$ be the number of times the distance $d$ is determined, and suppose the $d_i$ are ordered such that\[f(d_1)\geq f(d_2)\geq \cdots \geq f(d_k).\]Estimate\[\max (f(d_1)-f(d_2)),\]where the maximum is taken over all $A$ of size $n$.

### 支持理由

- 问题目标是估计一个极值函数，不要求分类所有最优点集；这给计算搜索和构造优化留下空间。
- 已知备注给出 n log n 下界和更强猜想，说明已有可复现的起点，AI 可以围绕该构造做变体搜索，而不是从零开始。
- 距离多重度可以被完全程序化计算，候选点集的有限规模证据容易验证，适合自动化实验。
- 若候选构造来自整数格点或圆上格点，许多计数步骤可转化为除数函数、平方和表示数等数论对象，比较适合模型辅助推导。
- 形式化证明可用于检查排序、多重度、删除扰动后差距保持等局部论证，降低构造性证明中的错误率。

### 主要障碍

- 完整上界很可能需要强的单位距离/重复距离或 incidence geometry 技术；这类上界通常远超单纯计算可发现范围。

- f(d2) 的压制是核心障碍：许多自然高重复距离构造会同时产生多个高频距离，使 gap 变小。
- 有限规模搜索很容易被低维格点伪模式误导，无法直接推出渐近结果。
- 问题未形式化，且几何距离相等涉及实数平方距离、同构消除和退化情形，形式化成本不低。

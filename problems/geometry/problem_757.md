## 原问题

Let $A\subset \mathbb{R}$ be a set of size $n$ such that every subset $B\subseteq A$ with $\lvert B\rvert =4$ has $\lvert B-B\rvert\geq 11$. Find the best constant $c>0$ such that $A$ must always contain a Sidon set of size $\geq cn$.

### 支持理由

- 题目已形式化，且核心对象可离散化到 A subset N，适合计算枚举、SAT/ILP 证书、Lean/Isabelle 等形式化验证。
- 局部约束只涉及每个四元子集，禁形规模小；这类问题常可通过有限构型分类、超图独立数界、局部到全局的不等式获得可验证进展。
- 已知界很接近但仍有明显差距：9/17 与 4/7 之间留下可攻空间，AI 可能通过系统化搜索发现改进常数或验证现有证明。
- 上界由具体构造族给出，下界由组合论证给出，这种双侧结构适合模型分别做反例搜索和证明证书生成。

### 主要障碍

- 最佳常数可能依赖无限族极值结构，而不是小规模搜索可直接发现的单一模式。
- 从有限枚举或数值 LP 证书提升为对任意 n 的严格证明是主要难点。
- Sidon 子集最大大小与局部四点距离条件之间存在全局依赖，简单贪心或局部修补可能无法闭合到最优常数。
- 若现有改进 Ma-Tang 已使用复杂结构分解，模型需要准确复现并进一步创新，难度高于常规形式化验证。

### 需要的验证

- 重新形式化差集大小条件与“五个不同距离”表述的等价性，并验证 Sidon 子集定义在实数/整数归约下保持不变。
- 对小 n 做穷举或约束求解，比较最大可避免 Sidon 子集比例是否逼近 4/7、9/17 或其他候选常数。
- 若提出新下界，需要机器可检验的禁形分类、线性不等式证书或完整归纳/分解证明。
- 若提出新上界，需要给出无限构造族，并严格证明其满足四点条件且所有 Sidon 子集大小不超过候选比例。

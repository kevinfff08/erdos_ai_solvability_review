# Source snapshot

This directory preserves the input catalog used by the published results.

- `erdos_problems_full.json`: full 682-problem source snapshot.
- `index/problems.csv`: one-row-per-problem catalog and historical V1 fields.
- `index/categories.csv`: category counts and membership metadata.

The source snapshot is not itself a current-status authority. V2 conclusions and dated evidence are stored in `results/reviews/`.
